# Student Management System

## Project Description

A Python-based Student Management System developed using Object-Oriented Programming concepts.

## Features

- Student information management
- Result calculation
- Undergraduate and Graduate student handling
- Object-oriented design


## OOP Concepts Used

### 1. Class and Object
Classes are created and objects are generated from them.

### 2. Encapsulation
Private attributes:
- __email
- __marks

### 3. Inheritance
Child classes:
- UndergraduateStudent
- GraduateStudent

inherit from Student.

### 4. Polymorphism
Same method behaves differently for different student objects.

### 5. Method Overriding
get_student_type() is overridden in child classes.

### 6. Method Overloading
add_marks() accepts multiple arguments using *args.
